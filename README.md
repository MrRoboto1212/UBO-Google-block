Stolen from https://github.com/nickspaargaren/no-google - blocking analytics and fingerprintning URLs 

Modified to work on uBlock Origin. This is a blanket anti-Google filter, meaning no YouTube, no Drive, nor any other Google website. If you want to use these, use an alternative or temporarily disable the filter entirely. (Personally, I find the latter easier than editing out every line related to unique instances.) 

Currently no way of whitelisting specific sites underneath individual filters. Captchas can have the potential to break on any website, though very unlikely. 

Websites will load faster when using this.
